🧩 Problems Covered
1807 — Evaluate the Bracket Pairs of a String
Replaces bracketed keys with their corresponding values from a knowledge base.

Concepts: HashMap, String processing

345 — Reverse Vowels of a String
Reverses only the vowels in a given string while keeping all other characters unchanged.

Concepts: Two pointers, String manipulation

126 — Word Ladder II
Finds all shortest transformation sequences between two words.

Concepts: BFS, graph traversal, backtracking

1190 — Reverse Substrings Between Each Pair of Parentheses
Reverses characters contained within matching pairs of parentheses, including handling nested parentheses.

Concepts: Stack, String manipulation

1111 — Maximum Nesting Depth of Two Valid Parentheses Strings
Splits a valid parentheses sequence into two sequences while minimizing their maximum nesting depth.

Concepts: Greedy approach, parentheses depth

292 — Nim Game
Determines whether the first player can win a Nim game under the given rules.

Concepts: Game theory, mathematical observation
